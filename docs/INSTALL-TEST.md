# OPPO 影像备份 0.7.19 · 安装与朋友测试

这是 Apple 芯片 Mac 的 MTP 测试版，最低系统为 macOS 15。它没有 Developer ID 签名或 Apple 公证；请只从本仓库的 0.7.19 Release 下载。

## 安装

1. 从 Release 下载 `OPPOBackup-0.7.19-macOS15-AppleSilicon-UNNOTARIZED.zip` 和同版本的 SHA-256 校验文件。
2. 在“终端”运行下面的命令，并将文件名替换为下载位置的实际路径：

   ```sh
   shasum -a 256 "$HOME/Downloads/OPPOBackup-0.7.19-macOS15-AppleSilicon-UNNOTARIZED.zip"
   ```

   将显示的 64 位校验值与 Release 中的校验文件比较，必须完全一致。
3. 双击 ZIP 解压，将 `OPPO 备份·受控测试版.app` 拖入“应用程序”，然后打开。
4. 未公证 App 可能触发开发者验证提示。只有在校验码一致且你确认下载来源可信时，才按 macOS 的开发者验证流程继续。如果系统提示 App 已损坏或包含恶意内容，请停止并联系发布者，不要绕过该阻止。

## 第一次测试

1. 解锁 OPPO 手机，连接 Mac，在手机 USB 通知中选择“文件传输／MTP”，并允许文件访问。
2. 打开 App，确认手机型号和 MTP 状态。点“重新检测”会重新识别当前设备并刷新素材清单，不会复制文件。
3. 在 Mac 上选择一个全新、独立的空测试目录。首次备份会处理手机 `DCIM`、`Pictures` 范围中当前可识别的照片、RAW 和视频。开始前确认这些目录内没有你不愿复制到测试 Mac 的素材。
4. 检查确认页显示的素材数量和目标位置，再开始备份。完成后检查 `照片`、`RAW`、`视频` 三类目录。

## 增量与恢复测试

1. 首次备份完成后，在手机上拍摄少量测试照片、RAW 或视频。
2. 重新连接并解锁手机，选择“文件传输／MTP”，在 App 中点“重新检测”。
3. 选择“只备份新增素材”。预期是已核验的副本不再复制，新增或上次未完成项目被补入相同测试库。
4. 测试拔线恢复时只使用少量测试素材和本轮测试目录；发生中断后重新连接，再按 App 指引恢复。

请每位测试者使用自己的手机和独立测试目录。报告 Mac 芯片、macOS 版本、手机型号、MTP 状态、素材数量级和结果即可。不要分享照片、RAW、视频、设备序列号或包含个人文件名的日志。测试目录中会写入媒体副本；手机原件不会被 App 修改。

## 已知限制

- 只处理 MTP 可见的 `DCIM`、`Pictures` 中受支持的照片、RAW 和视频，不备份应用数据或手机整机内容。
- 只支持 Apple 芯片 Mac；Intel Mac 不适用。项目中的其他构建脚本不代表此 0.7.19 应用包支持 Intel。
- 未对所有 OPPO 型号完成覆盖，也未在干净的第二台 Mac 上完成此 ZIP 的安装验收。MTP 可用性会随机型、手机授权、系统版本和线材而变。
- 增量识别依赖来源路径和文件大小；同路径、同大小但内容改变的文件可能无法识别为变化。
- 这只是受控测试包，不是正式发行版。请不要把结果保存到正式备份目录或 LaCie 资料中。
